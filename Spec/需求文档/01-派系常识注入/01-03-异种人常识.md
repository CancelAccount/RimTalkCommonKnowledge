## 3. 功能需求

### FR-9 异种人常识（需 Biotech DLC）

与派系常识**同构**：同一对钩子（FR-1）、同一套幂等与补齐机制（FR-5）、同一标签策略与重要度分档（FR-4 / D43），只是主体从派系换成异种人。差异点如下。

#### FR-9.0 DLC 门控

- 前置判定 `ModsConfig.BiotechActive`（证据 ㉕）。为假时**整体跳过**，只记一条汇总日志，不报错。
- 未启用时 `DefDatabase<XenotypeDef>` 为空、`FactionDef.xenotypeSet` 为 `null`、`XenotypeDefOf.Baseliner` 为 `null`——**任何访问前都必须先过门控与判空**，否则 NRE（证据 ㉕）。

#### FR-9.1 异种人集合来源（D12）

对 FR-2 筛出的每个**有效派系**，按**游戏生成成员时的同一口径**合并三处来源，得到该派系的异种人概率分布：

| 来源 | 路径 | 说明 |
| --- | --- | --- |
| 派系定义 | `faction.def.xenotypeSet` | 可能为 `null`；遍历只能用 `Count` + 索引器 `set[i]`（**`xenotypeChances` 字段是 private**，无 `XenotypeChances` 属性、无 `AllXenotypes`、无 `GetXenotypeChance`，证据 ㉕） |
| 主理念 | `faction.ideos?.PrimaryIdeo?.memes[i].xenotypeSet` | `MemeDef.xenotypeSet` 是 public 字段；理念可追加异种人倾向（证据 ㉕） |
| **兵种级** | `faction.def.pawnGroupMakers[].options[].kind.xenotypeSet` | `PawnKindDef.xenotypeSet`；游戏在 `PawnGenerator.XenotypesAvailableFor` 里对它**无条件累加**（与 `useFactionXenotypes` 无关，后者只管派系级是否参与）。这是「派系级未声明、特色异种人只写在兵种上」这类派系的**唯一来源**（D40、证据 ㊶） |
| 基础异种人补差额 | `faction.def.BaselinerChance` | `xenotypeSet == null` 时返回 `1f`；非 null 时返回 `1 - Σ(非基础异种人 chance)`（证据 ㉕） |

- 三处来源按**游戏口径累加**（同名异种人 `chance` 相加、跳过基础异种人），并取**并集**作为世界级异种人集合：每个出现的**非基础**异种人 `XenotypeDef` 各生成 1 条常识；基础异种人由 `BaselinerChance > 0` 补差单独成条。
- 单条来源的 `XenotypeChance` 是 `public class`，字段 `xenotype`（`XenotypeDef`）与 `chance`（`float`）均 public（证据 ㉕）。
- 遍历 `PawnKindDef.xenotypeSet` 只读字段、不改 Def、不落盘，无副作用。
- **禁止**靠地图 pawn 统计：新档 `StartedNewGame()` 时玩家地图上只有己方 pawn，没有敌对派系成员（证据 ㉕）。

#### FR-9.2 内容模板

前缀 `【异种人】`（D15），单行无换行（证据 ⑧），重要度 `0.80`（D43：异种人归入「其它」档，与社区库异种人 / 谱系条目齐平）。

| 段 | 模板 | 取值来源 | 缺省处理 |
| --- | --- | --- | --- |
| ① 是什么 | `【异种人】{LabelCap}：{description}` | `XenotypeDef.LabelCap`（继承自 `Def`）、`XenotypeDef.description`（继承自 `Def`） | `description` 为空则退用 `descriptionShort`（`[MustTranslate]`，证据 ㉕）；两者皆空则只留异种人名（模板 `XENOTYPE_SEG_INTRO_BARE`）；**社区库已覆盖该异种人 → 省略描述、退用只留名字的模板**（D43「定义原文让位」，判定键 = `XenotypeDef.LabelCap`，并排除本 mod 自己的 `【异种人】` 条目） |
| ② 标志性基因 | `标志性基因：{g1}、{g2}、{g3}、{g4}。` | `XenotypeDef.genes` / `XenotypeDef.AllGenes`（同引用），取 `GeneDef.LabelCap` | `genes.Count == 0` → 写「没有任何特殊基因，是自然演化的人类。」（基础异种人即此情况，证据 ㉕）；`xenotypeGeneCount == 0` → 整段跳过 |
| ③ 出没派系 | `他们主要在{派系A}、{派系B}出没。` | 反向索引 FR-9.1 的结果 | 开关 `includeFactionXenotypeRefs` 关闭、或无派系引用 → 整段跳过 |

**反向索引口径**（FR-9.2 ③）：索引 = 遍历 FR-2 筛出的**有效派系**，取各派系的 FR-9.1 **显式集合**（`FactionDef.xenotypeSet` ∪ 主理念 `memes[].xenotypeSet` ∪ 兵种级 `PawnKindDef.xenotypeSet`），建立「异种人 → 派系名」映射。**不含基础异种人补差**——若含，则每个派系都会把智人种列为「出没派系」，列表噪声极大。索引建立必须先于条目遍历（`FactionKnowledgeComponent` 中先 `BuildXenotypeFactionIndex` 再取条目集合）。

**标志性基因的挑选口径**（复用游戏自身的展示顺序，不自创排序）：

1. 候选 = `xenotype.genes` 中 `displayCategory != GeneCategoryDefOf.Miscellaneous` 的基因（`GeneCategoryDefOf.Miscellaneous` 为 public，证据 ㉕）；
2. 排序键：`gene.displayCategory.displayPriorityInXenotype` 降序 → `gene.displayOrderInCategory` 升序（两者均 public，证据 ㉕）；
3. 取前 `xenotypeGeneCount` 个。
4. 可选的类型标注（`biostatArc > 0` → 超凡基因；`biostatMet` 符号 → 增益/代价，证据 ㉕）默认**不写**，避免文案噪声；仅在预设里需要时启用。

#### FR-9.3 标签与幂等

- `tag = XenotypeDef.LabelCap`（如「骠骑种」），`matchMode = Any`（D14）。**不加**通用词。
- 幂等判定与清理：`FindKnowledge(LabelCap)` 中 `content.StartsWith("【异种人】")` 的条目属本 mod 管理范围；新开档先删后写，读档缺失才写（同 FR-5）。
- 与派系条目**同 tag 撞车**时不覆盖、两条都保留，仅记日志告警（[§6 决策表](01-08-决策表.md#6-决策表) D23）。
