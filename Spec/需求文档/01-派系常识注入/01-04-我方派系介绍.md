## 3. 功能需求

### FR-13 我方派系介绍

为**玩家自己的派系**（`faction.IsPlayer`）单独写一条常识：殖民者对白提到自己派系名时，能带出「我是谁、我在哪、我有什么」。内容走**独立**模板（不套用 FR-3 的五段：我方派系没有「与我方关系 / 好感度」可言，且需要据点名、飞船名、财富等专属信息）。

**前缀与标签口径**：内容前缀同 `【派系】`（D8 幂等标记，两类派系共用同一管理范围）；标签主词同 `faction.Name`（走 FR-4 / D3）。普通派系仍按 FR-4 并列特征异种人名；**我方派系的标签 = 派系名 + 我方逆重飞船名**（玩家 / 殖民者提到飞船名也能带出该条目，D35），**不并列特征异种人名**（我方派系内容不含「成员构成」段，并列会错配）。

| 段 | 模板 | 取值来源 | 缺省处理 |
| --- | --- | --- | --- |
| ① 身份 | `「{name}」是我们自己所属的派系。` + `我们的开局剧本是「{剧本名}」。` | 派系名取 `Faction.Name`；剧本名取 `Find.Scenario.name`（D38） | 身份句**始终保留**；剧本句在读不到剧本 / 剧本名为空时**省略** |
| ② 人口 | `我们有{殖民者数}名殖民者{附加}。`，附加形如 `，另有2名临时成员、1名囚犯、3名奴隶` | 遍历 `PawnsFinder.AllMapsCaravansAndTravellingTransporters_Alive`，按**互斥优先**顺序判定：囚犯（`Pawn.IsPrisonerOfColony`）→ 奴隶（`Pawn.IsSlaveOfColony`）→ 临时成员 → 殖民者（`Pawn.IsFreeNonSlaveColonist`） | 殖民者数**始终显示**（可为 0）；附加子句**只列人数非零的类别**，三类全零则整句只有殖民者数 |
| ③ 机械族 | `我们还有{型号构成}。`，型号构成形如 `3台清扫机、2台建造者` | 需 Biotech：同一遍历范围内 `Pawn.IsColonyMech` 逐台按其 `kindDef.LabelCap` **分型号计数**，**按型号名升序**输出 | **未启用 Biotech → 整段跳过**；启用但 0 台 → 替代句 `我们目前没有友方机械族。` |
| ④ 据点 | `我们的据点是{据点列表}。` | 遍历 `Find.Maps` 取 `IsPlayerHome` 且**非**飞船着陆生成的地图，取其 `map.Parent.LabelCap`（`MapParent` → `WorldObject.LabelCap`），多据点**全部列出**并以 `、` 连接 | 无据点 → 替代句 `我们目前还没有固定的据点。` |
| ⑤ 气候 | `殖民地所在位置的气候是{生物群系名}。` | `Find.AnyPlayerHomeMap.Biome.LabelCap`（`Map.Biome` 即 `TileInfo.PrimaryBiome`） | 无主基地地图 / 群系不可读 → **整段跳过** |
| ⑥ 逆重飞船 | `逆重飞船「{飞船名}」已在此停留{停留时长}。` | `ModsConfig.OdysseyActive` 为真时遍历 `Find.Maps`：`GravshipUtility.PlayerHasGravEngine(map)` 判定 + `GravshipUtility.TryGetNameOfGravshipOnMap(map, out name)` 取名；停留时长 = `TicksGame − map.generationTick`，**仅当 `map.wasSpawnedViaGravShipLanding` 为真时**才能反推 | 无 Odyssey / 无飞船 → **整段跳过**；有飞船但读不到着陆时刻 → 降级为 `我们有一艘逆重飞船「{飞船名}」。`（**不编造时长**） |
| ⑦ 建立时长 | `这个派系已经建立了{时长}。` | `Find.TickManager.TicksGame` | `TicksGame` 不可得 → 记 0（即「刚建立」） |
| ⑧ 财富 | `主基地的财富约为{财富值}。` | `Find.AnyPlayerHomeMap.wealthWatcher.WealthTotal`（`float` → 取整） | 无玩家据点地图，或读取抛异常（地图地形索引越界）→ 整段跳过并**只告警一次**（RK-23） |

- **剧本名口径**（证据 ㊴ / D38）：取 `Find.Scenario.name`（`[MustTranslate]` 本地化文本，即玩家在剧本界面看到的原文，如「迫降」「失落的部落」）。**只取名字**——不取 `summary` / `description`（二者含 `\n`，会破坏上游单行格式），名字本身也过一次 `ToSingleLine` 消隐患；**不反查 `ScenarioDef`**（`Scenario` 无 `def` 字段，且读档后是 Scribe 反序列化的新实例，引用比对失效）。剧本句**不进质变指纹**，交由覆写冷却控制。
- **人口的四类口径**（证据 ㊱）：**殖民者** = `IsFreeNonSlaveColonist`（自由人，不含奴隶 / 囚犯 / 临时成员）；**临时成员** = `QuestUtility.IsQuestLodger()`（任务寄居者：难民、来做客的等）**或** 由我方招待的来客（`HostFaction == 我方 && guest.GuestStatus == GuestStatus.Guest`）；**囚犯** = `IsPrisonerOfColony`；**奴隶** = `IsSlaveOfColony`。
- **人口遍历范围**：`AllMapsCaravansAndTravellingTransporters_Alive`（所有地图上 + 商队 / 运输船 / 当前逆重飞船里活着的单位），故**外派商队中的殖民者也计入**；`!pawn.RaceProps.Humanlike` 排除动物，亚人由 `IsColonist` 自身排除；**机械族非人形，故 ③ 段的统计必须放在人形过滤之前**，否则会被一并排掉。名单中「地图」一侧实为 `mapPawns.AllPawns`（已生成 + 容器 / 休眠舱内未生成者），**尸体已被 `AllPawnsUnspawned` 内部排掉**，故无需再判 `Dead`。（证据 ㊱）
- **机械族口径**（证据 ㊳）：台数走 `Pawn.IsColonyMech`（= `ModsConfig.BiotechActive && RaceProps.IsMechanoid && Faction == 我方 && MentalStateDef == null && (HostFaction == null || IsSlave)`，**自身已含 Biotech 门控**）；**型号取 `Pawn.kindDef.LabelCap`**（机械族的「型号」即其兵种，如清扫机 / 建造者），按**型号名升序**输出「N 台某型」——排序是为内容可复现（`Dictionary` 遍历顺序会随增删而变）。**不自行判断 Def / 自行拼条件**。（曾取 `MechanitorUtility.IsColonyMechRequiringMechanitor()` 写「失去监管」子句，现按用户要求移除，见 D37。）
- **气候口径**（证据 ㊳）：取主基地地图所属生物群系名（`Map.Biome.LabelCap`，而 `Map.Biome` 即 `TileInfo.PrimaryBiome`），与游戏内世界地图的「生物群系」口径一致；只在**主基地**（`Find.AnyPlayerHomeMap`）上取，与 ⑧ 财富同源。
- **时长文案**：统一用 `GenDate.ToStringTicksToPeriod(ticks, allowSeconds: false)`（游戏本地化的「X 年 Y 天」式），**不自行拼数字**。
- **据点排除飞船地图**：飞船着陆生成的地图其 `Parent.LabelCap` 由飞船名派生，与 ⑥ 段重复，故 ④ 段跳过 `map.wasSpawnedViaGravShipLanding` 的地图。
- **建立时长的口径局限**（已知取舍）：`Faction` **没有任何记录创建时刻的字段**（证据 ㉝），世界生成期的 tick 也未与本派系挂钩，故「建立时长」只能退化为**游戏已进行时长**（`TicksGame`）。若有 DLC/存档引入更精确来源，此项再收紧。
- **质变指纹**（对接 FR-11 / FR-12）：我方派系的「质变」= **派系名 + 据点集合 + 飞船集合 + 殖民者数 + 奴隶数**（拼接成分隔符指纹字符串），五者任一变化即视为质变、**立即重写**；⑦ 建立时长、⑧ 财富、**囚犯数与临时成员数**（难民 / 来客来去频繁）、**① 剧本名、③ 机械族型号构成、⑤ 气候**（剧本名整局不变、只有切换语言时才变；③ 机械族型号构成与 ⑤ 气候是用户明确要求「不立刻更新」——机械族会持续充放电、机械师更替也频繁，进指纹会导致高频立即重写；型号名排序保证同集合下内容稳定）**刻意不进指纹**，其更新交由 `REWRITE_COOLDOWN_TICKS`（3 天）冷却控制。
- **好感度一律不取**：我方派系既不参与 FR-11.4 的「仅好感度波动」判定，**也不发生好感度取值本身**——`PlayerGoodwill` / `PlayerRelationKind` 对玩家派系自身会触发引擎报错并 NRE（RK-22 / 证据 ㉞），必须在取值表达式处先判 `faction.IsPlayer`。
- **财富读取须就地降级**：`WealthTotal` 不是纯读取——它会按需触发**全图财富重算**，而重算按 `cachedTerrainMarketValue[terrainDef.index]` 取地形价值，遇到未被 `DefDatabase` 登记的地形（`Def.index` 停在默认 `ushort.MaxValue`）会抛 `IndexOutOfRangeException`。该异常与原版告警链路（`Alert_NeedJoySources`）同源，**不是本 mod 引起的**；但既然本 mod 也会读它，就必须 try/catch 只省略财富段（RK-23 / 证据 ㉟），不能让外部数据异常连累整条我方派系条目。
- **名字会变，故识别不靠名字**（D35）：我方派系的标签含派系名与飞船名，两者都会变——开档时玩家派系**尚无自定义名**（`HasName` 为假，`Name` 回退为 `def.LabelCap`，即「新移民」），玩家改名后标签变；飞船建成或改名后标签也变。若仍按「主键 = 当前派系名」查库，改名后**查不到旧条目**：旧条目会以旧名残留成重复项，且提到旧名还会命中陈旧内容。故对我方派系改用**内容里的固定句** `是我们自己所属的派系。`（`PLAYER_SEG_IDENTITY_SUFFIX`）识别条目（与名字无关），重写时先删旧的再按新名 / 新飞船名建新的。**旧名不保留**（用户选定）：改名后提到旧名不再命中，库里始终只剩一条。
- **存量存档自动迁移**：以旧口径写入（无飞船名标签）的条目，也会被上述固定句识别到；首次同步若判定需重写（改名 / 飞船变化 → 指纹变化 → 质变），旧条目一并删除，不留重复。若无需重写（内容一致）则原样保留，不做多余写入。
- **依赖降级**：无 Odyssey DLC 时 ⑥ 段整体缺席且不报错；无 Biotech 时 ③ 机械族段整体缺席（无机械族可言，写了只是噪声）；无 Ideology / Biotech 时 ② 人口段与 ⑧ 财富段照常（人口判定不依赖 DLC，奴隶判定在无 Ideology 时为 0）。（证据 ㊱、㊳、㉜）
