## 1. 诉求与现象

| 场景 | 现状 | 期望 |
| --- | --- | --- |
| 条目上万时拖动滚动条 | 滚动内容高度 = 条目数 × 70（上游 `RowHeight = 70f`，证据 ㊾），滑块被压到几乎不可拖 | 列表按块 / 模组 / 子页分短，滑块可用 |
| 找某块 / 某 mod 来源的常识 | 条目 `tag` 是 Def 标签、正文不含块名 / 模组名，上游搜索只匹配 `tag` / `content`（证据 ㊿） | 按「块 → 模组」两级直接定位 |
| 想自建一组常用条目 | 上游无「子页 / 收藏」概念 | 可新建 / 重命名 / 删除自定义子页，手动勾选条目归集 |
| 唤出管理页面 | 只能绕「设置 → 本 mod 设置项」 | 上游常识库界面直接给一个入口按钮 |

---

## 2. 机制

- **滚动条被压短是结构性的**：上游 `Dialog_CommonKnowledge` 的行高固定 `RowHeight = 70f`，内容高度随条目数线性增长；`Widgets.BeginScrollView` 无「最小滑块长度」机制（证据 ㊾、㊿）。**唯一务实解法是缩短列表**（分组 / 筛选）而非改上游。
- **条目无来源字段是结构性的**：`CommonKnowledgeEntry` 只有 `tag` / `content` / `importance` / `category` 等字段，既不记「所属块」也不记「来源 mod」；块 / 模组信息只存在于随包导入包的文件布局中（证据 ㊿）。故来源只能由本 mod **反查**导入包得到。
- **本页只读**：不新增 / 不删除上游条目，不改变注入与匹配行为；自定义子页只保存条目 id，落在本 mod 设置文件里。

| 维度 | 影响 |

| 回滚 | 关闭入口按钮 / 不打开即零影响；删除本 mod 设置字段即回滚 |

### 7.1 验收标准

1. **入口可用**：设置页「打开常识管理页面」按钮可唤出窗口；上游常识库不可用时按钮置灰并给出 tooltip 提示。
2. **滑块可用**：选中任一块 / 模组 / 子页后条目列表显著变短，滚动条滑块可正常拖动。
3. **来源定位**：预设库块 / 模组节点能列出对应条目；行内显示「块 / 模组」来源；搜索支持按块名 / 模组名过滤。**只列库内确有條目的块 / 模组**——未订阅 / 未启用的 mod 条目不会被导入，其节点不出现（不建空子页）；整组无可见块时连「预设库」分组标题也不显示。
4. **勾选归集**：勾选若干条目 →「勾选项加入本页」后，该自定义子页出现这些条目且不重复；「移出本页」后消失。
5. **子页管理**：可新建 / 重命名 / 删除子页；重命名与删除有内联确认，删除后其成员不回写上游库。
6. **持久化**：关闭设置并重开游戏后，自定义子页（名称 + 成员）保留；不写入上游常识库（上游界面看不到子页）。
7. **只读无损**：本页任何操作都不新增 / 不删除上游条目；点「刷新」重新取快照并剔除已失效的条目 id。（本条只读口径已由 [05 D51](05-常识条目编辑.md) 修订为可写）
8. **降级**：导入包缺失 / 读取失败时，来源索引退化为空，「全部 / 本 mod / 玩家自建」三类仍可用，仅记一次日志。
9. **上游入口按钮**：上游常识库界面工具栏出现「常识管理」按钮，点击打开本 mod 管理页面；已打开时重复点击不叠窗口；悬停有说明；上游方法改名导致补丁未生效时不显示按钮、只记一次日志，上游界面其余部分不受影响。
10. **滑动批量选择**：条目列表按住左键划过各行可把连续多行批量刷成同一勾选状态（起始行决定笔刷状态，往回复涂即撤销）；单击仍只切换单行；复选框与计数随拖动实时更新。
