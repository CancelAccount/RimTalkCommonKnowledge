## 0. 一句话目标

新开档时，把世界地图上每个派系（含隐藏派系，见 D39）的**身份、意识形态、与我方关系、领袖与据点**、**玩家自己派系的介绍（开局剧本 / 人口 / 机械族 / 据点 / 气候 / 逆重飞船 / 建立时长 / 财富）**，以及**与该派系相关的异种人（Xenotype）设定**整理成「常识」写入 RimTalk-Expand Memory 常识库；对白提到派系名或异种人名时自动带入。
