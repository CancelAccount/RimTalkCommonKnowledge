## 1. 诉求与现象

| # | 场景 | 现状 | 期望 |
|---|---|---|---|
| 1 | 觉得某条标签 / 正文 / 重要度不合适 | 本管理页只读，无修改入口（[03 §2.1 L26](03-常识管理页面.md)） | 选中条目即可编辑并保存 |
| 2 | 想手写一条新常识 | 页面无新增入口（新增只能去上游界面） | 页面内「新增条目」，填标签 / 正文 / 重要度 |
| 3 | 不想要某条（含已注入旧档的条目） | 页面无删除入口；删导入文件只影响今后新档 | 页面内删除，单条与勾选批量均可 |
| 4 | 编辑本 mod 自动注入的条目 | FR-11 定时刷新发现内容不一致即删旧建新，编辑被覆盖（[01-05 L19-L25](01-派系常识注入/01-05-刷新与冷却.md)） | 可锁定该条目，锁定后不被自动覆盖 |
| 5 | 想暂时停用某条但不想删 | 无入口 | 编辑时可切换启用状态（待拍板，见 D52） |

## 2. 机制

- **上游字段可直接写**：`CommonKnowledgeEntry.tag / content / importance / category / isEnabled` 均为 `public` 字段（取证核对清单已登记，[02 §4 L100](02-接口取证证据表.md)）；改值后**必须** `entry.InvalidateCache()`，否则匹配仍用旧标签缓存（[02 L163](02-接口取证证据表.md)）。
- **上游提供 Update API**：`CommonKnowledgeAPI` 有四个 `public static` 更新方法，均返回 `bool`（找不到 id 返回 `false`）：`UpdateKnowledge(id, content)`（改正文 + `InvalidateCache` + 同步向量库）、`UpdateKnowledgeTag(id, tag)`（改标签 + `InvalidateCache`）、`UpdateKnowledgeImportance(id, importance)`（内部 `Clamp01`）、`SetKnowledgeEnabled(id, enabled)`。桥接层组合这四者即可，不必自行取实例赋字段。
- **覆盖路径**：`FactionKnowledgeComponent.SyncFactionKnowledge` 对每派系查 `managedIds`；内容不一致 → `Remove` 全部旧 id → `AddLore` 重建（`FactionKnowledgeComponent.cs#L244-L254`）。锁定豁免点在「拿到 managedIds 之后、删除重建之前」。
- **单行约束**：`content` 含 `\r` / `\n` 会破坏上游导入导出格式，保存前强制校验（取证 ⑧，[02 L40](02-接口取证证据表.md)）。

## 4. 候选做法

| 方案 | 做法 | 落点 | 覆盖 | 副作用 | 结论 |
|---|---|---|---|---|---|
| 编辑入口-A | 独立编辑对话框 `Dialog_EditKnowledgeEntry`（标签 / 正文 / 重要度 / 锁定开关） | 新 `Verse.Window` | 字段多也清晰，可复用于新增 | 多一个窗口类 | ✅ |
| 编辑入口-B | 列表行内联展开编辑 | 管理页内 | 无新窗口 | 正文较长时行高与滚动错乱 | ❌ |
| 锁定语义-A | 锁定**仅防覆盖**：跳过删旧建新；条目被手动删除后重注属正常注入行为，删除即视为放弃锁定 | 刷新组件 + 锁定集合清理 | 语义简单可预期 | 删注入条目后会被重新注入（需界面提示） | ✅ |
| 锁定语义-B | 另存「派系身份键」，锁定同时防删除后重注 | 需身份键与解锁路径 | 永久屏蔽 | 与「想删但删不掉」纠缠，复杂 | ❌ |
| 锁定存储-A | 锁定集合存 `FactionKnowledgeComponent`（`ExposeData` 存档内） | 组件新增持久化字段 | 语义正确，不依赖 id 随机性 | 需新增存档字段 | ✅ |
| 锁定存储-B | 存 `FactionInfoSettings`（跨存档） | 仿子页存储 | 实现省事 | 若 id 非纯随机可能误锁他档条目，危害为该派系永不刷新 | ❌（待取证前不采用） |

## 5. 影响面与副作用

| 面 | 结论 |
|---|---|
| 存档 | 组件新增锁定 id 集合的 `ExposeData` 字段（仅新增键，旧档读取为空集合，不破坏旧档）；上游条目字段本来就可写，不改上游存档结构 |
| DLC | 无新增依赖；锁定检查对各 DLC 派系一视同仁 |
| 翻译 / 加载序 | 新增界面文案走现有 `FactionKnowledgeConfig.Manager` 常量；不改变加载序 |
| 展示 | 操作栏由现有两行重新分区（条目操作 / 子页操作）；列表行对锁定条目加锁定标识；编辑本 mod 注入条目时提示建议锁定 |
| 性能 | 锁定集合用 `HashSet<string>`，每派系同步仅一次 O(1) 查询；编辑对话框仅打开时存在 |
| 误操作 | 删除（尤其批量）须二次确认并显示条数；编辑保存失败回显原因、不落半成品 |
| 边界提示 | 删除本 mod 注入条目后，定时刷新仍会重新注入——永久不要该类条目应关对应开关（[设置键](01-派系常识注入/01-06-配置·日志·界面.md)）；此提示须出现在删除确认中 |
| 回滚 | 功能纯增量；回滚只需移除入口，库内已改 / 已删条目无法自动复原（故删除前确认） |
